# عجلة المشاعر (تطبيق مستقل على الجوال)

التطبيق ملفات ثابتة فقط: لا خادم ولا قاعدة بيانات، ولا يخرج شيء من جهازك إلا إن أضفت مفتاح API.

## تثبيته على جوالك
1. استضفه مجاناً: GitHub Pages (مستودع عام) أو Cloudflare Pages. ارفع محتويات هذا المجلد كما هي.
2. افتح الرابط من الجوال:
   - أندرويد (Chrome): القائمة ثم «تثبيت التطبيق».
   - آيفون (Safari): مشاركة ثم «إضافة إلى الشاشة الرئيسية».
   سيظهر بأيقونته الخاصة ويفتح كتطبيق مستقل.

## التحليل
- الافتراضي: تحليل داخلي مجاني يعمل بدون إنترنت.
- اختياري: من «تحليل بالذكاء الاصطناعي» أضف مفتاحك من console.anthropic.com (يُحاسَب الاستخدام بالاستهلاك، فضع حداً للإنفاق).

## ملاحظات
- لا تضع مفتاحك داخل الملفات؛ أضفه من الصفحة فقط.
- السجل والمفتاح يُحفظان على الجهاز نفسه فقط.
